# hfs-check-rs

Недеструктивный чекер Rejetto HFS 2.x на **CVE-2024-23692** (анонимный SSTI → RCE через `?search=`) с интерактивным шеллом.

![Rust](https://img.shields.io/badge/Rust-1.8x%2B-orange) ![CVE](https://img.shields.io/badge/CVE--2024--23692-critical) ![License](https://img.shields.io/badge/license-MIT-green) ![CI](https://github.com/Lolicks/hfs-check-rs/actions/workflows/build.yml/badge.svg)

> ⚠️ Используйте только в рамках письменного разрешения и согласованного скоупа.

## Зачем

Баннер `Server: HFS 2.3m` ещё не означает, что макросы исполняются — кастомные шаблоны могут не отражать `?search=`. Чекер подставляет случайный cookie-токен и смотрит, вернулся ли он из шаблона вместе с `%version%`. Ничего на сервере не изменяется.

### Вердикты

| Вердикт | Значение |
|---|---|
| `vulnerable` | Подтверждено: макросы исполняются |
| `echo_only` | Макросы отражаются в HTML, но не исполняются |
| `not_vulnerable` | Баннер есть, токен не отразился |
| `not_hfs` | Сервер не на HFS |
| `unreachable` / `error` | Сеть недоступна |

## Запуск

Без аргументов — меню:

```
1) Проверить одну цель
2) Проверить список из targets.txt
3) Интерактивный шелл (из found.txt)
4) Справка
0) Выход
```

Формат целей: `host:8000`, `host:80,8000,8080`, `host:8000-8010`. Без порта — 80.
`targets.txt` ищется в текущей папке, затем рядом с exe. Поддерживаются UTF-8, UTF-16 и Windows-1251.

Напрямую:

```powershell
hfs-check.exe 10.0.0.5:8000
hfs-check.exe help
```

## Отчёт и шелл

`found.txt` создаётся рядом с бинарником и содержит **только подтверждённые** цели, по одной строке, без дублей:

```
10.0.0.5:8000
```

Пункт 3 меню читает `found.txt`, показывает нумерованный список и предлагает выбрать цель. Перед входом в шелл уязвимость проверяется повторно.

В шелле:

| Команда | Действие |
|---|---|
| `<cmd>` | команда через `cmd /c` (префикс не нужен) |
| `ps <code>` / `ps` | PowerShell через `-enc` (UTF-16LE base64), многострочный режим |
| `cd [path]` | смена каталога, сохраняется между командами |
| `help`, `history`, `clear`, `exit` | встроенные |

PS-синтаксис (`Get-…`, `$var`, `[type]`, `| Where-Object`, `if (…)`) определяется автоматически.

## Сборка

```powershell
cargo build --release
```

CI при пуше собирает Windows `.exe` и статический Linux `x86_64-unknown-linux-musl`, по тегу `v*` публикует оба в релиз.

## Оптимизации

- Асинхронные raw-сокеты `tokio`, асинхронный DNS; оценка сети и 3 SSTI-пробы уходят **одной волной** вместо последовательных ретраев со `sleep`.
- 32 параллельные цели, connect-timeout 1.5 с, total 5 с.
- Без `regex`: ручной парсер заголовков, `<RESULT>…====`, HTML-unescape.
- `lto`, `codegen-units=1`, `panic=abort`, `strip`.
